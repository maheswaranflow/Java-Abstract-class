Abstract Class – Delivery Method

Objective

To design a Java program using an abstract class "DeliveryMethod" with an abstract method "estimateTime()", and implement it using the "ExpressDelivery" class.

Concept Used

- Abstract Class
- Abstract Method
- Inheritance
- Method Implementation

Program

The program defines an abstract class "DeliveryMethod". The "ExpressDelivery" class extends it and provides the implementation for the "estimateTime()" method.

How to Run

1. Install Java JDK.
2. Open the project folder in VS Code or any Java IDE.
3. Compile the program:

javac Main.java

4. Run the program:

java Main

Output

Estimated delivery time: 1-2 days

Result

Thus, the Java program using an abstract class and abstract method was successfully implemented and executed.
